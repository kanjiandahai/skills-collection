# earnings-digest · 财报要点

把财报与业绩说明压成**可比的要点卡**：数字、指引变化、口径差异，不做买卖结论。

> **声明**：本 skill 只提供信息整理与工作流模板，**不构成投资建议**，不提供买卖时机或收益承诺；投资决策与风险由用户自行承担。

## 何时用

- 季报/年报刚出，需要快速消化
- 要对比「指引 vs 实际」或同比/环比
- 整理电话会/说明会纪要要点

## 工作流

1. **锁定文件**：财报 PDF、新闻稿、补充材料、电话会实录；记下报告期与发布日。
2. **抽核心表**：营收、毛利/经营利润、净利、EPS、自由现金流、资产负债关键项；标注 GAAP/非 GAAP。
3. **看指引**：下季/全年指引是否上修下修；与共识（若有公开）并列表，不臆测。
4. **分部与质量**：分业务/地区、一次性项目、会计政策变更；单独标出。
5. **输出**：要点卡 + 待验证问题清单；禁止推荐买卖。

## 成功标准

- 关键数字可回溯到来源页码或表格
- 指引变化一目了然；明确写出「非投资建议」
