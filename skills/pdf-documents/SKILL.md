# pdf-documents

围绕 PDF 的读写与组装：先定「可读编辑还是印刷定稿」，再选工具链。

## 何时用

- 生成报告/说明书 PDF
- 合并、拆分、旋转、抽页
- 提取文本/表格，或填写可填表单

## 工作流

1. 确认输入输出：已有 PDF 还是从 Markdown/HTML 渲染；是否要可复制文本、书签、目录。
2. **生成**：Markdown/HTML → PDF（如 `typst`、`pandoc`、headless Chrome 打印）；注意中文字体嵌入。
3. **编辑/拆合**：用成熟库或 CLI（如 `pypdf`、`qpdf`）做页级操作；保持原有旋转与盒子信息。
4. **提取**：文本层优先；扫描件需 OCR 时明确告知质量限制。
5. 交稿前打开抽查：字体缺字、空白页、页序、链接是否可点。

## 原则

- 印刷稿嵌入字体；勿依赖对方机器上的字体
- 大文件先拆任务再合并，避免内存暴毙
- 表单填写保留字段只读/只写语义，不破坏现有签名域（除非用户要求）

## 成功标准

- 目标页数与内容齐全；关键页截图或文本抽查通过
- 中文不乱码；合并后页序正确
