# spreadsheet-xlsx

面向助手的 **表格工作流**：公式可重算、格式可读、改旧表不破坏约定。

## 何时用

- 新建或修改 `.xlsx` / `.csv` / `.tsv`
- 清洗错位表头、脏行，整理成正规表
- 汇总、对比、简单模型（含公式与图表）
- 用户点名某个表格文件并要求处理

主交付若是 Word/HTML/幻灯片，即使中间用到表，也不抢主技能；Google Sheets 仅 API/在线协作场景另议。

## 工具怎么选

| 任务 | 优先 |
|------|------|
| 带格式/公式的 `.xlsx` 新建与编辑 | `openpyxl` |
| 批量分析、CSV/TSV、清洗 | `pandas`，再写回 xlsx/csv |
| 图表 | `openpyxl.chart` 或先汇总再制图 |
| 快速扫内容 | 按工作表列出标题与样例行；精确定位单元格用坐标 API |

缺依赖再安装；能 import 就直接写脚本。

## 工作流

1. 确认目标：新建 / 编辑 / 分析 / 可视化，以及输出格式。
2. **改旧表**：先摸清既有约定（输入格颜色、已有公式、表名、冻结窗格），只改该改的区域，不重写无关公式。
3. **派生值写公式**，不要只把 Python 算死的数字贴进去（除非用户只要静态快照）。
4. 有公式时，在环境允许下 **重算并缓存结果** 再交付，避免对方打开全是空值。
5. 版式重要时做目视检查：列宽、数字格式、表头是否醒目。

## 公式与引用

- 用单元格引用，少写魔法数字：`=H6*(1+$B$3)` 优于 `=H6*1.04`
- 分清相对/绝对引用；复杂逻辑拆辅助列，保持可读
- 慎用 `INDIRECT` / `OFFSET` 等易失函数；避免依赖特定 Excel 365 动态数组（`FILTER`/`XLOOKUP`/`SEQUENCE` 等）除非用户环境明确支持
- 交稿前排查 `#REF!` `#DIV/0!` `#VALUE!` `#N/A` `#NAME?`、循环引用、差一行的区域

## 新建表的格式约定

- 表头与输入区、结果区视觉区分（底色或加粗），但不要给每个有字的格子都加框
- 日期像日期、百分比与货币用对格式；默认百分比常保留 1 位小数（数据特性优先）
- 列宽行高可读，避免文字溢进邻格；区块之间留空行/空列分隔
- **给别人填的模板**：附简短图例（哪些格可改）+ 一行真实格式的示例；**编辑已有文件时不要擅自加示例行**
- 假设、口径、硬编码常量写在表内可见处（旁注或批注），有来源就写来源

## 编辑已有文件

- 用户规格优先：工作表名、列名、公式原文能保留则保留
- 先找输入区（常靠字体色/底色标记），只写入那里
- 不顺手「重构」整本工作簿，除非用户要求

## 成功标准

- 文件可打开；约定的表名与列齐全
- 公式在重算后无错误（或已标明继承自原文件的错误并举证）
- 关键汇总可用公式追溯；格式不影响阅读

## 反模式

- 把分析结果只写死数字，源一变表就废
- 全表密密麻麻边框与彩虹底色
-  silently 改掉用户原有公式或命名
