# macro-calendar · 宏观日历解读

把宏观日程译成**观察框架**：发布时间、市场通常盯什么、如何记预期与结果；不做仓位建议。

> **声明**：本 skill 只提供信息整理与工作流模板，**不构成投资建议**，不提供买卖时机或收益承诺；投资决策与风险由用户自行承担。

## 何时用

- 本周有 CPI/非农/利率决议等，需要预习
- 要把「预期 vs 公布」记成可回看笔记
- 团队统一宏观事件的记录模板

## 工作流

1. **列日历**：事件名、地区、发布时间（含时区）、前值/预期（来自公开汇总则注明来源）。
2. **解释权重**：该数据通常影响什么利率路径/风险偏好讨论；避免玄学因果。
3. **设观察点**：关注的分项（如核心 CPI）、修订、发言人要点。
4. **公布后**：记实际值与即时市场反应（事实描述）；区分相关与因果。
5. **归档**：一页「事件卡」入库；声明非交易信号。

## 成功标准

- 时区与时间正确；预期来源可追溯
- 无「根据数据应该做多/空」类措辞
