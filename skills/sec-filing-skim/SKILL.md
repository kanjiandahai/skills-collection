# sec-filing-skim · 公告/10-K 速读

用固定路线图速读长披露文件，抽出**风险、变化、现金与或有事项**；通用流程，不绑单一数据商。

> **声明**：本 skill 只提供信息整理与工作流模板，**不构成投资建议**，不提供买卖时机或收益承诺；投资决策与风险由用户自行承担。

## 何时用

- 面对 10-K/10-Q、年报、招股书、重大公告不知从哪读
- 只要「相对上期变了什么」
- 要给他人做披露速读纪要

## 工作流

1. **认文件**：类型、报告期、提交日、修订版标记。
2. **先读变化**：MD&A 对比、近期事件、风险评估新增删除。
3. **财务与现金**：主表、流动性、债务到期、回购/分红政策描述。
4. **法律与关联**：重大诉讼、关联交易、控制权、审计意见异常。
5. **产出**：2–4 页速读纪要 + 页码索引；不构成投资建议。

## 成功标准

- 关键结论能指回章节/页码
- 区分「公司自述」与「第三方解读」
