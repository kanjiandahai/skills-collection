# market-brief · 行情简报

把公开行情与事件收成**可读的简报**，标注数据时点与来源，不做买卖建议。

> **声明**：本 skill 只提供信息整理与工作流模板，**不构成投资建议**，不提供买卖时机或收益承诺；投资决策与风险由用户自行承担。

## 何时用

- 用户要「今天/本周市场怎么样」的结构化摘要
- 需要晨会/收盘简报骨架（指数、板块、事件）
- 要把多源行情笔记压成一页要点

## 工作流

1. **定范围**：市场（A股/港股/美股/全球）、时段、关注板块或标的清单。
2. **收事实**：指数涨跌、成交额、主要板块涨跌幅、重要个股异动；只用不争议的公开数据。
3. **挂事件**：财报、政策、宏观数据、地缘等，区分「已发生」与「待验证传闻」。
4. **写简报**：按 概览 → 板块 → 个股/主题 → 日历/风险提示 输出；每条尽量带来源或时点。
5. **边界声明**：文末注明不构成投资建议；缺数据处写「未核实」而非编造。

## 成功标准

- 读者 2 分钟内看清「发生了什么」与「还看什么」
- 数字带时点；无荐股、无目标价、无仓位指令
