# portfolio-review · 持仓回顾

在**用户给出持仓与基准**的前提下做回顾清单：暴露、集中度、漂移与下次检视项。不代为下单。

> **声明**：本 skill 只提供信息整理与工作流模板，**不构成投资建议**，不提供买卖时机或收益承诺；投资决策与风险由用户自行承担。

## 何时用

- 月度/季度想复盘自己的持仓表
- 担心单票或单行业过重
- 要把「计划 vs 实际权重」对齐

## 工作流

1. **收输入**：持仓列表（标的、数量/权重、成本或入场逻辑）、基准、约束（现金比例、禁投等）。缺数据先问清，不臆造仓位。
2. **算暴露**：按资产类、行业、地区、单一发行人集中度做表；标出超限项。
3. **对照目标**：与目标权重/再平衡规则比较；列出漂移最大的几项。
4. **事件对齐**：近期财报、分红、到期、再融资是否影响持仓逻辑（仅记录，不给买卖指令）。
5. **输出**：回顾备忘 + 待决策问题；声明由用户自行决策，不构成投资建议。

## 成功标准

- 集中度与漂移有数字依据
- 无自动下单话术；风险与待办分列清楚
