# agent-browser

把网页任务做成 **可观察、可重试** 的浏览器步骤：先稳定选择器与成功条件，再执行。

## 何时用

- 「帮我在网页上点/填/下」
- 验证部署后的页面状态
- 需要登录态下的操作（配合安全的登录流程，不把密码写进 skill 正文）

## 工作流

1. 明确 URL、目标状态（看见什么文案/URL/元素即成功）、是否允许写操作。
2. 选工具：环境已有的浏览器自动化（Playwright/Puppeteer/agent-browser CLI 等）；优先官方文档里的命令。
3. **小步执行**：导航 → 等待关键元素 → 操作 → 断言；每步可截图留证。
4. 选择器优先 `getByRole` / 标签文本 / `data-testid`，少用脆弱的深层 CSS。
5. 失败时记录最后 URL、可见错误、截图；修正等待或选择器后重试，不要盲刷。

## 安全

- 不在仓库或聊天记录里保存明文密码；一次性验证码按宿主安全通道处理
- 默认不爬取或批量导出用户未授权的隐私数据
- 对生产环境的删除/支付/发送类操作，先复述影响再执行

## 成功标准

- 达到约定的页面状态，并有简短证据（截图或关键 DOM 文本）
- 步骤可复述，他人能按同一路径重跑
