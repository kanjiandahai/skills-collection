# valuation-sanity · 估值 sanity check

检查估值故事是否**自洽**（倍数、增长、利润率、情景），指出脆弱假设；不是出具目标价。

> **声明**：本 skill 只提供信息整理与工作流模板，**不构成投资建议**，不提供买卖时机或收益承诺；投资决策与风险由用户自行承担。

## 何时用

- 看到 PE/PS/EV-EBITDA 想核对是否合理
- 自建 DCF/倍数表，要找假设漏洞
- 对比两家公司估值口径是否一致

## 工作流

1. **统一口径**：用的是哪个价格、净利/EBITDA、稀释后股本、净债；跨市场汇率。
2. **拆驱动**：隐含增长率、利润率、资本成本或退出倍数是否写得清楚。
3. **情景**：乐观/基准/悲观各一页表；忌只给单点。
4. **对照**：历史自身区间、近邻公司（注明不可比处）；不把「便宜」当成推荐。
5. **输出**：假设清单 + 最脆弱的 3 条；明确非投资建议、非正式估值意见。

## 成功标准

- 读者能指出「哪个假设动了结论就翻」
- 不出现「建议买入/卖出」或伪装精确的目标价
