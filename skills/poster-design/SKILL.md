# poster-design

做 **单页、强视觉** 的海报或静态稿：先定视觉立场，再出图。原创构图，不模仿在世艺术家个人风格，不复刻受保护的现成作品。

## 何时用

- 活动海报、招聘/发布会主视觉、社媒方图/竖图
- 「好看一点的封面图 / 宣传页」，且重点是画面而非长文
- 交付 PNG 或单页 PDF

长文排版、多页幻灯片分别交给文档流程或 `pptx-deck`。流程图逻辑用 `flowchart-mermaid`。

## 开工前确认（缺则问一句）

1. **用途与场景**（线下张贴 / 手机屏 / 网页头图）
2. **尺寸或比例**（如 A3、1080×1920、1:1）；未指定则默认 1080×1350（约 4:5）
3. **必须出现的文字**（活动名、时间地点、一句 slogan）；能少则少
4. **品牌色 / 禁忌**（若有）

## 工作流

1. **读需求当素材，不当填空模板**：抓住情绪、主题词、场合。
2. **先写 4–6 段「视觉哲学」**（可单独 `.md`）：运动感或静谧感、空间与形体、色彩与材质、尺度与节奏、层级与留白、工艺完成度。再提炼一条不直白说破的概念线。
3. **再做画面**：有限色板、克制字体、清晰边距；文字当视觉元素，不是说明书。
4. **终检**：锐利、对齐、无出画、无叠压遮挡关键信息；留白够、层级一眼能读。

## 画面原则

- 目标比例：**约 90% 视觉，10% 必要文字**（用户点名要文案多时再放宽）
- 主色 ≤ 3（含中性色）；强调色用于唯一焦点
- 字号层级分明：主标题远大于辅助信息；中西文混排注意基线与字重
- 边距充足；关键图形与文字勿贴边或出画布
- 避免剪贴画堆砌、无意义光效、低对比灰字
- 需要照片时用用户提供素材或明确可商用的来源；不要假冒真实名人肖像去站台

## 技术路径（按环境）

| 交付 | 做法提示 |
|------|----------|
| PNG | 矢量/绘图库、设计工具导出，或助手侧图像生成后按尺寸裁切 |
| 单页 PDF | 矢量优先，便于打印；嵌入字体或转曲线 |
| 多尺寸 | 先定主构图，再导出变体，勿简单拉伸变形 |

脚本或生成参数应写清：宽高、主色 hex、字体名、边距。中文字体按运行环境选用已安装字体，并在交付说明里写明。

## 成功标准

- 有简短视觉哲学（或等价说明）支撑构图选择
- 单页成图，焦点清晰，必要文字可读
- 尺寸符合约定；无版权仿冒与低质糊边

## 反模式

- 把 PPT 封面逻辑硬套成海报（大段 bullet）
- 未定尺寸就出图导致打印裁切翻车
- 文案喧宾夺主，画面只剩底图
